# 飞致云五层自动化：两档测试说明

> 日期：2026-09-07  
> 给谁看：公司电脑上打飞致云 4090 离线包的人  
> 一句话：**不是很多套测试，就是同一条脚本两个档。** 先测生死，再测全量。手点页面不算验收。

分层定义仍以 [测试总纲.md](./测试总纲.md) 为准。上机清单、已知坑、端口细节见 [GPU全量校验手册.md](./GPU全量校验手册.md)。实例怎么租、怎么退还见 [Featurize 4090 按量实例操作手册](../deploy/2026-09-07_Featurize4090按量实例操作手册.md)。

---

## 1. 整体思路

生产栈在飞致云（RTX 4090，离线包 `容器化部署/gpu`）。测试在**公司电脑**跑，经 SSH 隧道打过去。

```text
飞致云：六个容器一直开着（postgres / llama / embed / vision / api / web）
公司电脑：一条脚本 gpu-five-layer.ps1
         ├─ gpu-quick  日常薄切 = 测生死
         └─ gpu-full   要纲全量 = 测完整 GPU 验收路径
```

两档不是两套系统，只是参数不同。quick 过了，再跑 full；不要拆成一堆零散 curl / 手点页面。

**全量 ≠ 测试总纲里出现过的每一个历史命令。**  
全量 = 总纲里的 **五层 GPU 验收路径**（Gate + L0/L1 + L2 + L3 九个 `e2e-real` spec + L4 评测/识图/日志）。下面这些**故意不跑**，也不能当 GPU 证据：

- 英文 `benzene` 快路径、`npm run test:e2e`（MSW 假后端）
- `int-test-task11.sh` / AutoDL cron / `download-analysis.ps1`
- `npm run test:e2e:real`（pretest 会打本机 `:15001` + benzene）
- 手点九个页面、文件夹 2、覆盖率、Benchmark
- 总纲理想线「结论 ≥90% / Top-5 ≥85%」（对照历史即可，差了只进 `alerts[]`，不单独否决）

## 2. 五层在这条线上怎么排

```text
Gate0  飞致云有卡、模型、docker-up 已起     （上机操作，不在脚本里）
  ↓
Gate1  六个容器健康（含 vision :8083）       两档都跑；挂了整轮停
  ↓
L0/L1  本机架构测试 + 单元 + vitest          full 默认跑；quick 可 -SkipWhitebox
  ↓                                          白盒 FAIL 只记报告，不挡后面 GPU 层
L2     一条安全距离 HTTP                     两档都跑；挂了整轮失败
  ↓
L3     Playwright e2e-real（九个页面 spec）  quick 去掉 llm-quality；full 全跑
  ↓
L4     63 条评测 + 识图 + D1–D6 日志         仅 gpu-full
```

| 层 | 测什么 | 通过长什么样 |
|----|--------|----------------|
| **Gate1** | llama :8080 / embed :8081 / vision :8083 / api `/health/live` / nginx `/nginx-health` | 五个全绿。本机 Docker 占 8088 时脚本改绑 `18088/15000/…`，否则会测到本机五容器（没有 8083） |
| **L0** | `ArchitectureTest` | 记入 summary；FAIL 不挡 L2 |
| **L1** | `Agent1.Tests`（排除 Integration）+ `vitest` | 同上 |
| **L2** | `POST /api/Compliance/check` | **≥3 秒** 且 `toolsUsed` 含 **`GetSafetyDistance`**。问句用「甲类仓库与明火点最少隔开多少米」。带「甲醇 / 硝酸 / 安全距离 / 苯」会走关键词快路径（亚秒），**不是 GPU 证据** |
| **L3** | `agent1-web/e2e-real/` 九个 spec | 页面、权限、真实数据。quick：36 条（无 llm-quality）。full：含 llm-quality。页面里 `160ms 跳过耗时下限` 仍可能出现，不抵消 L2 |
| **L4** | `POST /api/Eval/run` 等到 `completed`；识图 `POST /api/Multimodal/analyze`；切片 docker 日志做 D1–D6 | 评测必须跑完；识图 HTTP 200 且 ≥3 秒。指标退化只进 `alerts[]` |

脚本 **exit 1** 当且仅当：Gate1 失败，或 L2 失败，或 L3 失败，或 full 的评测没 `completed`，或 full 缺识图 / 识图失败。

## 3. 两档对照

| | **gpu-quick（测生死）** | **gpu-full（测全量）** |
|---|---|---|
| 什么时候跑 | 栈刚起来、改过登录/隧道之后 | quick 已经绿了，要写 GPU 验收 |
| 大约多久 | 15–25 分钟 | 约 1 小时（评测最久） |
| Gate1 / L2 | 跑 | 跑 |
| L0/L1 | 可 `-SkipWhitebox` | 应跑（不要 Skip） |
| L3 | 去掉 `llm-quality` | 九个 spec 全跑 |
| L4 | **不跑** | 评测 + 识图 + 日志 |
| 能写 | 薄切健康 / `gpu-quick` 通过 | 按手册 **`gpu-full` 通过** |
| 不能写 | **不能**写「GPU 全量通过」 | 不能拿白盒 PASS 抵消 8083 或评测失败 |

2026-09-07 飞致云 4090 已跑通 **gpu-quick**（Gate1 + L2 3.6s `GetSafetyDistance` + L3 36/36，白盒跳过）。**gpu-full 尚未跑。**

## 4. 公司电脑命令

工作目录：`agent-system`。飞致云 SSH **端口每次新租会变**，从实例页抄，下面 `65037` 只是当时的端口。

会弹出 **另一个 SSH 窗口**，飞致云密码打在那个窗口，不要打在跑脚本的窗口。隧道窗口保持开着，不要在探测阶段往脚本窗口回车。

```powershell
cd "d:\桌面\agent\开源大赛提交\前后端合并代码\agent-system"
# 先按离线包说明设置 E2E_ADMIN_PASSWORD / E2E_AUDITOR_PASSWORD / E2E_VIEWER_PASSWORD

# 档 1：测生死（日常）
.\scripts\gpu-five-layer.ps1 -SshPort 65037 -Profile gpu-quick

# 档 2：测全量（要纲）— 图片必须是本机真实 jpg/png/webp，不要用占位路径
.\scripts\gpu-five-layer.ps1 -SshPort 65037 -Profile gpu-full -VisionImage "D:\path\to\ghs-or-tank.jpg"
```

常用开关：

- `-SkipWhitebox`：跳过本机 L0/L1（quick 排障时用；full 不要加，否则白盒仍是 SKIP）
- `-SkipTunnel`：隧道已经手工开好
- `-AltTunnelPorts`：强制绑 `18088/15000/18080/18081/18083`

产出：`eval_reports\<yyyyMMdd_HHmmss>\five-layer-summary.json`。  
full 另有 `eval.json`、`comparison.json`、`analysis.md`、`log_slices/`。

看 summary 里每一层的 `PASS` / `FAIL` / `SKIP`，不要只看 Playwright 的 `36 passed`。

## 5. 飞致云上不要做什么

生产只跑**离线包**，不要在实例上 clone 源码、不要 `rebuild-llama`、不要 `docker compose down -v`（会丢库）。

登录账号见离线包说明（`.env` 的 `AUTH_ACCOUNTS_JSON`；需带 viewer 才有三条账号）。脚本用环境变量 `E2E_ADMIN_PASSWORD` / `E2E_AUDITOR_PASSWORD` / `E2E_VIEWER_PASSWORD`。

网页不要用 `http://workspace.featurize.cn:8088`。公司电脑走隧道：`http://localhost:18088`（本机 8088 已被 Docker 占用时）。

## 6. 这轮已经踩过、以后对照着看

1. **本机 Docker 占 8088/5000/8080/8081**  
   脚本必须改绑 18088/15000/…。否则 Gate1 会打到公司电脑那套**没有 vision** 的栈。

2. **登录 HTTP 500、`系统内部错误`**  
   不是密码错（密码错是 401）。compose 把 `AUTH_ACCOUNTS_JSON` 的引号剥掉了，容器里变成 `[{Username:admin,...}]`。修法见实例手册 [§2.3.2](../deploy/2026-09-07_Featurize4090按量实例操作手册.md)。`printenv` 必须能看到 `"Username"`。recreate `api` 后要等 `/health/live`，不要 sleep 8 秒就 curl（会 `Connection reset`）。

3. **L2 亚秒 + 工具名**  
   真实工具名是 `GetSafetyDistance`，不是手册旧写法 `CheckSafetyDistance`。问句若含「甲醇 / 硝酸 / 安全距离 / 苯」，`/api/Compliance/check` 走关键词快路径，0.6s 也会列出工具，**仍不是 GPU**。编排现用「甲类仓库与明火点最少隔开多少米」并加一次性编号，避免 quick 跑过之后 full 命中 API 内存缓存（0.12s 假失败）。

4. **L3 登录失败时不要干等 Playwright**  
   登录都 500 时 36 条会一条条超时。脚本在登录失败时会跳过 L3。

5. **识图**  
   `-VisionImage` 必须是真实图片。占位路径 → L4 识图 FAIL → full 整轮失败。  
   **只想补测识图：不要再跑 gpu-full。** 实例 SSH 里 curl，见手册 [§2.3.3](../deploy/2026-09-07_Featurize4090按量实例操作手册.md#233-单点识图--单点-l2不要为这一项再跑-gpu-full)。

6. **D1–D6 的 SSH 再要一次飞致云密码**  
   不是 Web 演示账号。`WARN: ssh docker logs exit=1` 常见于容器里没有 `/app/Data/eval_report.json`；评测 JSON 仍以 HTTP 拉到的 `eval.json` 为准，不单独否决。
