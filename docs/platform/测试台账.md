## CI 实际跑（真源）

| Job | 命令 | 失败条件 |
|-----|------|----------|
| `build-and-test` | `dotnet test Agent1.Tests --filter "Category!=Integration"` + coverlet | 测试失败；行覆盖较上次 artifact **下降 >2%** |
| `frontend-test` | `npx vitest run --coverage`（`agent1-web/`） | Vitest 失败 |
| `integration-test` | 临时 PG `:5432` + 根目录 `init_database.sql` + `dotnet test --filter "Category=Integration"` | 集成失败 |
| `docker` | 构建并推 GHCR（主分支） | 构建失败 |
| `benchmark` | API `127.0.0.1:5000` + `Benchmark.dll --light`（主路径，job 在 workflow 内） | P95 较 baseline **>50%** 或错误率 **>5%** |
| `notify` / `staging-deploy` | 可选邮件；SSH 拉预构建镜像 | 缺 secrets 则跳过 |

`ArchitectureTest/` **不是** CI 门禁。

## 不在 CI（本地 / 机房）

| 层 | 怎么跑 | 说明 |
|----|--------|------|
| Playwright Mock | `cd agent1-web && npm run test:e2e` | 文档曾写「CI 快速门禁」——**未接线**，只是本地门 |
| Playwright Real | `npm run test:e2e:real`（pre：`check-test-ids.mjs` + `health-check.ps1`） | 要真 API；默认 `:5000`；隧道须显式 URL |
| Playwright Demo | `npm run demo:record` | 必须 Nginx URL，禁止默认 Vite `:5173` |
| 无 GPU 评委 | `scripts/demo-compatibility` | README 路径 2；不进 CI |
| GPU 五层 | 见 `docs/infra/`；编排脚本 **不在本仓** | `gpu-full` 本轮未通过是锁定口径 |
| `scripts/test_rule_engine.sh` 等 | 裸机打本机 API | 非规范；`scripts/_legacy/` 更不是门禁 |

覆盖率：**没有**「绝对 60% 行覆盖」CI 闸；只有相对上次 **>2%** 回退。说明书里若写 60%，以本表为准。
