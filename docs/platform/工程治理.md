# 工程治理（第一阶段总闸）

公开作品名 **苍卫**。工程名 Agent1 / `agent-system`。

第一阶段把债登记清楚，并把**运维入口口径**对齐到本机 `:5000`。**不改规则引擎、双通道、种子。** 那两件是第二、三阶段。

从这里往下走：[工程债分拣](工程债分拣.md) → [页面完成度清单](页面完成度清单.md) → 需要血管时再打开 [系统血谱](系统血谱.md)。认路用 [目录地图.md](目录地图.md)。不要从测试总纲或 `docs/platform/skills/` 进门。

Agent 操作系统（防散落）：根目录 [AGENTS.md](../../AGENTS.md)、[运行时端口登记.md](运行时端口登记.md)、[测试台账.md](测试台账.md)、[开发会话纪要/](开发会话纪要/)、仓库 `.cursor/rules/` 与 `.cursor/skills/`。`docs/platform/skills/` 仍是方法底稿，不是 Cursor Skill。

## 三阶段

| 阶段 | 目标 | 动什么 |
|------|------|--------|
| **一 · 现在** | 治理体系可信、运维默认口对齐、Agent 不散落 | `docs/**`、治理文件、Issue/PR 模板、`AGENTS.md`、`.cursor/**`、辅助脚本的**默认 URL/监听口**、非规范脚本迁 `scripts/_legacy/`（不改判定逻辑） |
| **二** | 深化无 GPU 规则引擎 | 种子、`DeterministicRuleEngine`、配伍/距离覆盖（先查 [同源拷贝联动手册](同源拷贝联动手册.md)） |
| **三** | 双通道、真实场景、可追溯 | 事实/解释通道、审计字段、页面↔场景↔代码；必要时才调链路 |

```
Phase1 治理体系  →  Phase2 规则引擎  →  Phase3 双通道与可追溯
```

## 第一阶段冻结（禁止改）

- `Agent1/**`
- `Agent1.Api/**`
- `agent1-web/src/**`
- 迁移 / 种子 SQL（`init_database.sql`、`db/migrations/**`）
- CI job 逻辑（`.github/workflows/**`）

禁止「顺手」重命名 `ChemicalDatabaseService` / `ChemicalSubstanceDatabase`、清乱码块、扩种子、改评测白名单、改双通道、删侧栏页面。

## 第一阶段允许改

- `docs/**`
- 根目录 `AGENTS.md`、`CONTRIBUTING.md`、`SECURITY.md`、`CODE_OF_CONDUCT.md`
- `.cursor/**`（规则、技能；MCP 配置不含 token）
- `.github/ISSUE_TEMPLATE/`、`.gitee/ISSUE_TEMPLATE/`、`.github/pull_request_template.md`
- `scripts/_legacy/**`、`scripts/_scratch/**`（gitignore）：搬家隔离，不改判定逻辑
- 辅助脚本默认监听口 / `API_URL`（`scripts/start_services.sh`、根目录转发、`scripts/test_*.sh`、`agent1-web/scripts/health-check.ps1`、`agent1-web/vite.config.ts` 与 Real 档 Playwright **默认代理**）。隧道仍用显式 `15000`/`15001`，不改 SSH 工具本身。

## 硬规则（各阶段都有效）

1. **事实通道不交给模型。** 法规号、储存禁忌、安全距离由确定性代码给出；大模型只解释和建议。
2. **无 GPU 必须仍能出结构化结论。** 评委路径是 `docker-compose.demo.yml` + `scripts/demo-compatibility`（甲醇 × 硝酸 → 禁配 + GB 15603）。
3. **改同源拷贝组必须先查联动手册。** 拷贝组 1（物质 / 禁忌 / 距离 / 法规版本）从第二阶段起才允许动。
