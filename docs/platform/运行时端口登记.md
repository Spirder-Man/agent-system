# 运行时端口登记

**真源**。改默认口必须同批改本表，以及实际读取这些变量的 compose / `.env.example` / Vite / health-check。数字过期以本表 + `.env.example` 为准，不以聊天记忆为准。

阶段总闸：[工程治理.md](工程治理.md)。启动技能：`.cursor/skills/runtime-ports`。

## 默认口

| 角色 | 口 | 谁用 | `.env` 变量 |
|------|----|------|-------------|
| API 主机 | **5000** | Docker 映射、裸机、Vite 默认代理、CI benchmark、`demo-compatibility` | `API_PORT` / `DEMO_API_PORT` / `ASPNETCORE_URLS` |
| API 容器内 | 8080 | Kestrel；Nginx 反代 `api:8080`。不要在主机上当入口 | （compose 写死容器侧） |
| Vite 开发 | 5173 | 只 `npm run dev` / Mock E2E | — |
| Web Nginx | Linux **80**；Windows **8088**（`docker-up.ps1` 无管理员权限时） | 评委看页面 | `WEB_PORT` |
| PostgreSQL | 5432 | 全栈 compose、裸机、CI Integration | `DB_PORT` |
| PostgreSQL（demo 主机） | **5433** | 仅 `docker-compose.demo.yml` 映射，避免与全栈 PG 抢 5432 | `DEMO_DB_PORT` |
| llama LLM | 8080 | 推理 | `LLAMA_PORT` |
| llama Embed | 8081 | 向量 | `LLAMA_EMBED_PORT` |
| llama Vision | 8083 | OCR；显存不足可关 | `LLAMA_VISION_PORT` |
| 精排 reranker | 8082 | `appsettings.json` 有键，**compose 未部署**；默认关闭 | — |
| Prometheus | 9090 | 仅 obs overlay | `PROMETHEUS_PORT` |
| Alertmanager | 9093 | 仅 obs overlay | `ALERTMANAGER_PORT` |
| Grafana | 3000 | 仅 obs overlay；易与别的前端抢口 | `GRAFANA_PORT` |
| Pushgateway | 9091 | 评测推指标，可选 | — |
| SSH 隧道（本机） | 15000 / 15001 | **必须显式** `VITE_PROXY_TARGET` / `API_URL` / `health-check.ps1 -ApiUrl` | 禁止当默认 |
| IDE launchSettings | 52319 (https) / 52320 (http) | Visual Studio / `dotnet run` **带 launch profile**。日常脚本用 `--no-launch-profile` 打 **5000**。本阶段冻结，不改该文件 | — |
| Demo Playwright | 18088 | 本地 8088 被占时的录片 URL，须显式 `PLAYWRIGHT_BASE_URL` | — |

健康检查：`GET http://localhost:5000/health/live`。Swagger：`http://localhost:5000/swagger`。

## 互斥（不能同开）

| 组合 | 行不行 | 原因 |
|------|--------|------|
| 全栈 `docker-compose.yml` + `docker-compose.demo.yml` | **不行** | 都要主机 **API 5000** |
| 全栈 + 裸机 `start_services.sh` | **不行** | 同样抢 5000 / 8080 / 8081 / 5432 |
| 全栈 PG + demo PG | 可以（库） | demo 主机默认 **5433**；API 仍不能双开 |
| Vite `:5173` + Docker Nginx | 可以 | 两套前端；代理目标仍应是空闲的 API |
| 全栈 + `docker-compose.obs.yml` | 可以 | 另占 9090 / 9093 / 3000；3000 被占则改 `GRAFANA_PORT` |
| 日常开发 + IDE launchSettings 52320 | **不要** | 与规范入口 5000 分裂；不要把 52320 写进文档当默认 |

冲突时：**只改 `.env` 已有变量**，禁止 Agent 再发明第三套默认口，禁止把隧道口写进 Vite / 脚本默认值。

## 推荐组合

1. **有卡**：`scripts/docker-up` gpu → 浏览器 `WEB_PORT`，API `:5000`。
2. **无 GPU 评委**：`docker compose -f docker-compose.demo.yml up` + `scripts/demo-compatibility` → API `:5000`；前端可用 Vite `:5173`。
3. **只看 UI**：`cd agent1-web && npm run dev:mock`（不占 5000）。
4. **远程真 API**：自备 SSH 隧道后显式 `VITE_PROXY_TARGET=http://localhost:15001`（或实际转发口）。内部 SSH 脚本不在本仓。
