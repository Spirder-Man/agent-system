# 目录地图

给**人**认路。Agent 浓缩版在仓库根 [AGENTS.md](../../AGENTS.md)。阶段冻结见 [工程治理.md](工程治理.md)。

> 先认三个器官，再翻其余目录。生成物（`coverage/`、`bin/`、`obj/`、`dist/`）不当源码读。

## 系统怎么连

```
浏览器 → agent1-web（前台）→ Agent1.Api（传菜口 :5000）→ Agent1（厨房）
                                              ↓
                         PostgreSQL / SQLite 备胎 / llama.cpp :8080
                         knowledgebase（语料）  db/（迁移进 PG）
```

## 三个器官（改功能才进；第一阶段冻结）

| 目录 | 一句话 | 备注 |
|------|--------|------|
| [`Agent1/`](../../Agent1/) | 厨房：规则引擎、RAG、编排、审计 | 说明书：[../Agent1/说明书.md](../Agent1/说明书.md) |
| [`Agent1.Api/`](../../Agent1.Api/) | 传菜口：REST、JWT、健康检查 | 主机入口 **:5000**；容器内 8080 |
| [`agent1-web/`](../../agent1-web/) | 前台：Vue 3 + Vite + Element Plus | 禁止改 `src/`。测试在 `e2e` / `e2e-real` / `e2e-demo` |

## 测试与数据

| 目录 | 一句话 |
|------|--------|
| [`Agent1.Tests/`](../../Agent1.Tests/) | xUnit。CI 跑「非 Integration」；Integration 另 job + 临时 Postgres |
| [`Data/`](../../Data/) | 评测集 JSON。改它等于改黄金答案，本阶段不改 |
| [`db/`](../../db/) | 迁移与 schema。根目录另有 `init_database.sql`（demo compose 挂这份）。两份不一致是已知债，**本阶段不合并** |
| [`knowledgebase/`](../../knowledgebase/) | RAG 语料约定；国标全文不进 Git |
| [`Benchmark/`](../../Benchmark/) | CI 性能灯，不是日常入口 |
| [`ArchitectureTest/`](../../ArchitectureTest/) | 历史架构探针，**不是 CI 门禁**。化石，不删不进日常 |

## 运行与交付

| 目录 / 文件 | 一句话 |
|-------------|--------|
| [`scripts/`](../../scripts/) | 唯一允许的运维入口目录。规范入口见该目录 README |
| `scripts/_legacy/` | 已隔离的一次性 / AutoDL 脚本，**不是入口** |
| `scripts/_scratch/` | Agent 临时脚本（gitignore），收工必须删 |
| `docker-compose*.yml`、`Dockerfile*` | GPU 全栈 / CPU / 无 GPU demo / 观测 / staging |
| [`prometheus/`](../../prometheus/) [`grafana/`](../../grafana/) | 观测 overlay，默认不起 |
| [`models/`](../../models/) | GGUF 清单；权重复制不进 Git |
| [`docs/`](../README.md) | 说明书按模块；跨模块在 `docs/platform/`；历史在 `docs/_archive/` |
| [`.github/`](../../.github/) [`.gitee/`](../../.gitee/) [`.husky/`](../../.husky/) | 双托管 Issue/PR/CI 与提交钩子 |
| [`.cursor/`](../../.cursor/) | 本仓 Cursor 规则与技能（防散落操作系统） |

## 生成物（不要当源码翻）

`agent1-web/coverage/`、`agent1-web/dist/`、`eval_reports/`、`logs/`、`TestResults/*.trx`、`third_party/llama.cpp/`、`node_modules/`、`bin/`、`obj/`。

## 不要当入口

| 路径 | 为什么 |
|------|--------|
| 根目录 `start_services.sh` | 只转发到 `scripts/start_services.sh` |
| `scripts/_legacy/` | 历史脚本，行为与现网入口无关 |
| `prompts/`、`.agents/`、`.claude/` | 旧助手配置，不是 Cursor 技能 |
| [`docs/platform/skills/`](skills/) | 给人看的方法底稿，**不是** Cursor Skill，也不是 CI 门禁 |
| `Agent1.Api/Properties/launchSettings.json` | IDE 口 52319/52320，**不是**日常入口 |

端口互斥与默认口：[运行时端口登记.md](运行时端口登记.md)。测试以谁为准：[测试台账.md](测试台账.md)。
