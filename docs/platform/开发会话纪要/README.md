# 开发会话纪要

Agent **过程**写这里：这次动了什么、临时脚本去向、踩坑、台账改没改。

[CHANGELOG.md](../CHANGELOG.md) 只记克隆用户能感知的仓库变更。不要把纪要写成作品介绍，不要写评委/交差口径。

## 怎么写

1. 复制 [`_template.md`](_template.md) 为 `YYYY-MM-DD_短标题.md`（同一天多段工作就追加，或加 `-2`）。
2. 收工技能 `session-hygiene` 会要求填写「脚本去向」。
3. 非琐碎的仓库可见结果，另写一行 CHANGELOG。
