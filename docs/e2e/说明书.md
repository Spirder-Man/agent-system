# E2E 说明书

Playwright 三档都在 `agent1-web/` 下，验证浏览器里的流程。不测 xUnit。有卡复现走 [infra](../infra/说明书.md) 的 `docker-up gpu`。

## 边界

| 负责 | 不负责 |
|------|--------|
| Mock 档：CI 门禁、MSW、不碰 GPU | `Agent1.Tests` 单元/集成 |
| Real 档：真 API（本机 Docker；远程 API 时隧道自备） | 容器健康与评测（内部五层脚本不在本仓） |
| Demo 档：OS2026 录片 + 作品配图截取 | 改业务判定逻辑 |

## 三档对照

| 档 | 目录 | 配置 | npm 脚本 | 何时用 |
|----|------|------|----------|--------|
| Mock | `e2e/` | `playwright.config.ts` | `npm run test:e2e` | CI、无后端、只验 UI |
| Real | `e2e-real/` | `playwright.real.config.ts` | `npm run test:e2e:real` | 验真链路与 LLM 断言 |
| Demo | `e2e-demo/` | `playwright.demo.config.ts` | `npm run demo:record` | 大赛演示片；要 Nginx 生产 URL |

Mock 配置写明：E2E **不验证 LLM 推理质量**。Real 档才有 `llm-assertions.ts`。Demo **禁止默认打 Vite `:5173`**（DEV 登录会写假 token，片子作废），必须 `PLAYWRIGHT_BASE_URL` 指向 Nginx。

## 启动与开发

```bash
cd agent1-web
npm install
npx playwright install chromium   # 首次

# Mock（可无后端）
npm run test:e2e

# Real：先保证 API 健康。本机 Docker 默认代理 :5000。
#   PLAYWRIGHT_BASE_URL=http://localhost:8088 VITE_PROXY_TARGET=http://localhost:5000
npm run test:e2e:real

# 旧远程 GPU：自备 SSH 隧道后设 VITE_PROXY_TARGET=http://localhost:15001
# health-check.ps1 隧道: -ApiUrl http://localhost:15001
```

`test:e2e:real` 的 `pre` 会跑 `scripts/check-test-ids.mjs` 与 `health-check.ps1`。

### 环境变量

| 变量 | 含义 |
|------|------|
| `PLAYWRIGHT_BASE_URL` | Real/Demo 的浏览器入口 |
| `VITE_PROXY_TARGET` | Real 档 Vite 把 `/api` 转到哪 |
| `E2E_ADMIN_USER` / `E2E_ADMIN_PASSWORD` | 默认 admin / changeme |
| `DEMO_ALLOW_VITE` | 仅调试 Demo 打 Vite 时设 `1` |

## 对外契约

- Mock 档依赖 MSW 与 `src/test-ids.ts` 的稳定选择器。  
- Real 档依赖后端角色与演示账号。  
- Demo 配图输出目录：`docs/platform/os2026-figures/`（`capture-os2026-figures.spec.ts`）。

大赛录片脚本（仓库根）：[`scripts/record-os2026-demo.ps1`](../../scripts/record-os2026-demo.ps1)。成品 mp4 在 Gitee Release，不进 Git。

## 关键流程

1. **CI Mock**：起 `dev:mock` → chromium 跑 `e2e/*.spec.ts`。  
2. **Real 冒烟**：健康检查 → 登录 → 合规/巡检等 spec。  
3. **录片**：Nginx 已部署 → `PLAYWRIGHT_BASE_URL` → `os2026-demo.spec.ts` → `collect-video.ts` 收视频。

## 本模块怎么测

就是上表三条命令。不要用 Mock 档给评委证明 GPU 推理。GPU 容器总判定见 [../infra/2026-09-07_飞致云五层两档测试说明.md](../infra/2026-09-07_飞致云五层两档测试说明.md)（**gpu-full 本轮未通过**）。
