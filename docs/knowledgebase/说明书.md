## 边界（摘要）

| 负责 | 不负责 |
|------|--------|
| 三层模型：SQL 种子 / 可公开样例 / 国标全文+向量 | 编写 `init_database.sql`（归 db） |
| `国标/README.md`、`化工专业条例/README.md` 的自备说明 | 把 GB 全文提交进公开仓 |
| 虚构「园区规则」「历史案例」样例文本 | 在 Git 里分发 embedding |

甲醇×硝酸验收只用第 1 层种子，缺第 3 层不算这条验收失败。

容器内进程看到的路径是 `/app/knowledgebase`。本机完整语料在仓库外时，只在 `.env` 写 `KNOWLEDGE_BASE_PATH`，不要提交 `.env`。

离线大赛包语料在仓库外的 `cpu/knowledgebase`，见 [../infra/deploy/开源项目分发落地方案.md](../infra/deploy/开源项目分发落地方案.md)。
