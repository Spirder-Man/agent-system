# infra 说明书

把 PostgreSQL、llama.cpp、API、前端编成可启动的栈：Compose、镜像、脚本、可选观测。不改禁配规则，不写 Vue 页面。阶段总闸：[../platform/工程治理.md](../platform/工程治理.md)。本机 API **:5000**。

## 边界

| 负责 | 不负责 |
|------|--------|
| `docker-compose*.yml`、`Dockerfile*` | `Agent1` 业务代码 |
| `scripts/docker-up*`、下模型、demo 验收 | 在脚本里长期托管服务生命周期以外的「第二套启动器」（以现有 docker-up 为准） |
| Prometheus / Grafana 叠加 | 等保测评、生产备份 |
| 飞致云 / AutoDL / 3090 上机记录 | 把 gpu-full 未通过写成通过 |

**scripts 定位**：runbook 与编排入口，不是第二个应用运行时。

## 启动与开发

根 README 三条路径是规范入口（`docker-up` / demo compose + `demo-compatibility`）。裸机 `start_services.sh` 不是规范入口，默认监听也已改为 **5000**。此处只列命令：

```bash
cp .env.example .env          # 填 JWT_KEY、DB_PASSWORD
powershell -File scripts/download-models.ps1   # 或 bash scripts/download-models.sh

bash scripts/docker-up.sh gpu                  # Linux 有卡
# powershell -File scripts/docker-up.ps1 gpu   # Windows

# 无 GPU 演示
docker compose -f docker-compose.demo.yml up -d --build
bash scripts/demo-compatibility.sh
```

Windows 无管理员权限时 `.env` 设 `WEB_PORT=8088`。健康检查：`curl http://localhost:5000/health/live`。

观测：

```bash
docker compose -f docker-compose.yml -f docker-compose.obs.yml up -d
```

## 关键流程

1. **有卡完整栈**：下模型 → `docker-up gpu` → 浏览器打开 WEB_PORT → 储存兼容性。  
2. **无 GPU 演示**：demo compose + `demo-compatibility`，禁忌走确定性引擎。  
3. **有卡复现**：`docker-up gpu`。4090 上 `gpu-quick` 过、`gpu-full` 未过的记录见 [2026-09-07_飞致云五层两档测试说明.md](2026-09-07_飞致云五层两档测试说明.md)（内部 SSH 脚本不在本仓）。
