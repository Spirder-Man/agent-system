# agent1-web 说明书

Vue 3 + Vite 的合规审查界面。只展示、收集输入、带 JWT 调 API。禁配结论以后端为准。

## 边界

| 负责 | 不负责 |
|------|--------|
| 页面、路由角色守卫、Pinia、axios 拦截器 | 法规判定、RAG、哈希链 |
| 契约文件 `src/types/api.ts`（手工对齐 C# DTO） | 生成 OpenAPI |
| MSW Mock（`npm run dev:mock`） | 启动 PostgreSQL / llama |
| Vitest 组件/API 单测 | Playwright 三档（见 [e2e](../e2e/说明书.md)） |
| 生产 Nginx 静态资源（Docker `web` 服务） | 编写 compose 编排（[infra](../infra/说明书.md)） |

**依赖**：开发可零后端（Mock）；真数据需要 `Agent1.Api`。  
**契约**：[`src/types/api.ts`](../../agent1-web/src/types/api.ts) ↔ 后端 DTO，改一端必须改另一端。

## 目录地图

```
agent1-web/
  package.json              scripts: dev / dev:mock / test / test:e2e*
  src/
    pages/                  业务页面
    api/                    按域拆的 axios 封装
    stores/                 Pinia（auth 等）
    types/api.ts            前后端合同
    lib/axios.ts            JWT、刷新、错误码
    mocks/                  MSW handlers + 假数据
    router/index.ts         路由与角色
    components/ directives/
  e2e/ e2e-real/ e2e-demo/  见 e2e 说明书
  docs/                     仅历史稿；操作说明以本文为准
```

## 启动与开发

```bash
cd agent1-web
npm install
npm run dev:mock    # 只看 UI，不需要后端
npm run dev         # 经 Vite 代理打真实 API
```

| 模式 | 命令 | 行为 |
|------|------|------|
| Mock | `npm run dev:mock`（`--mode mock`） | MSW 拦截 `/api/*`，无网线出站 |
| 真后端 | `npm run dev` | 默认代理 `http://localhost:5000`；隧道须设 `VITE_PROXY_TARGET`（如 `:15000`） |

演示账号（仅本地）：`admin` / `changeme`。Mock 下密码策略以 handlers 为准，不要把 Mock 当成鉴权测试。

浏览器：Vite 默认 `http://localhost:5173`。Docker 生产入口为 Nginx（`WEB_PORT`，Windows 无管理员权限常用 8088）。

F12 控制台应看到 MSW 启动日志才说明 Mock 生效。架构细节：[../../agent1-web/src/mocks/README.md](../../agent1-web/src/mocks/README.md)。

## 关键流程

1. **储存兼容性**：登录 → `/storage/compatibility` 查甲醇与硝酸 → 展示禁止同库与 GB 出处（真后端时来自规则引擎；Mock 时来自 `mocks/data`）。  
2. **鉴权**：axios 附 Bearer；401 刷新；刷新失败清会话回登录。  
3. **改接口**：先改 `types/api.ts` → 改 `api/*.ts` 与 `mocks/handlers.ts` → 再改页面；后端同步 DTO。
