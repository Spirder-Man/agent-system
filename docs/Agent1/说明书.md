# Agent1 核心库说明书

法规条款、储存禁忌和安全距离由本库的确定性代码给出；大模型只解释和建议。HTTP 与页面不在本模块。

## 边界

| 负责 | 不负责 |
|------|--------|
| 双通道：C# 工具出事实，LLM 出解释 | REST、JWT、CORS、限流（[`Agent1.Api`](../Agent1.Api/说明书.md)） |
| RAG（NGram + 内存 BM25 + pgvector） | Vue 页面与 MSW（[`agent1-web`](../agent1-web/说明书.md)） |
| `DeterministicRuleEngine` 降级链、`ComplianceRuleEngine` 资产扫描 | Docker / 模型下载（[`infra`](../infra/说明书.md)） |
| 知识图谱、审计哈希链、会话记忆、漂移探针 | schema 与 SQL 种子（[`db`](../db/说明书.md)） |
| CLI 菜单宿主（`Program.cs`） | 国标全文（[`knowledgebase`](../knowledgebase/说明书.md)） |

**依赖**：PostgreSQL + pgvector；可选 llama.cpp（`LLM_ENDPOINT`、embedding `:8081`、vision `:8083`）；语料目录 `KNOWLEDGE_BASE_PATH`。

**被谁用**：`Agent1.Api` 项目引用 + DI；`Agent1.Tests` 测本库；CLI 可单独 `dotnet run --project Agent1`。

## 目录地图

```
Agent1/
  Program.cs              CLI 入口（不是 HTTP）

  appsettings.json
  Commands/               控制台菜单
  Config/                 AppConfig
  Models/                 领域模型
  Modules/                推理管线模块（合规、RAG、应急、图谱、工单…）

    AI/                   LlmService、ToolService
    Dialog/               AgentDialog、RAG、ChemicalRAG、IntentRouter
    Knowledge/            知识库、图谱、分块、抽取
    Orchestration/        规则引擎、巡检编排、定时扫描
    Compliance/           ResponseMerger 等结论合并
    DriftMonitor/         漂移测量与探针
    Eval/                 评测引擎
    Infrastructure/       DatabaseService、AuditService、ModuleDispatcher
    Memory/               短/长期记忆与响应缓存
    Security/             Token 黑名单、设备指纹
    Logging/ Monitoring/ Observability/
```

两个规则引擎不要混：

| 类型 | 文件 | 干什么 |
|------|------|--------|
| `DeterministicRuleEngine` | `Services/Orchestration/DeterministicRuleEngine.cs` | LLM 不可用、Function Calling 违约或 `LLM_OPTIONAL=true` 时的**查询降级**：门卫 + 责任链，结构化结论不读生成文本 |
| `ComplianceRuleEngine` | `Services/Orchestration/ComplianceRuleEngine.cs` | **资产扫描**：内置规则（如 SR-001 同库禁忌）对照台账生成 Finding |

## 启动与开发

本库不单独侦听端口。联调走 API：

```bash
# 无 GPU 时在 .env 设 LLM_OPTIONAL=true
dotnet run --project Agent1.Api
```

只跑核心逻辑测试：

```bash
dotnet test Agent1.Tests --filter "Category!=Integration"
```

CLI（菜单，不经 HTTP）：

```bash
dotnet run --project Agent1
```

关键配置在 `appsettings.json`，可被环境变量覆盖：`LLM_ENDPOINT`、`VectorSearch__EmbeddingEndpoint`、`MULTIMODAL_ENDPOINT`、`KNOWLEDGE_BASE_PATH`、`LLM_OPTIONAL`。完整列表见仓库 [`.env.example`](../../.env.example)。

默认 API 监听 **5000**（`ASPNETCORE_URLS` 或 `http://0.0.0.0:5000`）。血谱旧稿里的 5001 以代码与 compose 为准。

## 对外契约

- **给 API 的服务**：`AgentDialog`、`ILlmService`、`IToolService`、`IDatabaseService`、`IAuditService`、`IKnowledgeBaseService`、规则引擎与编排器，由 `Agent1.Api` 的 DI 注册。
- **给前端的 JSON 形状**：以后端 DTO 为准；前端对照 [`agent1-web/src/types/api.ts`](../../agent1-web/src/types/api.ts)，无 OpenAPI 生成。
- **法规白名单**：`RegulationRefs`；白名单外的 GB 号会从解释通道删掉。
- **审计**：`audit_logs` 应用层 SHA256 哈希链，见 [`db/说明书.md`](../db/说明书.md)。

## 关键流程

### 1. 储存兼容性（甲醇 × 硝酸）

请求进入 API → 核心工具查图谱/禁忌表 → 确定性结论带 **GB 15603** 出处 → LLM 只写说明。无 GPU 或熔断时走 `DeterministicRuleEngine`，验收不依赖 llama。种子在 `init_database.sql` 与 `db/migrations/002_chemical_knowledge_graph.sql`。

### 2. 对话 + 工具

`IntentRouter` 分流 → `AgentDialog` 编排 → `ToolService` 调 C# 工具 → `ResponseMerger` 合并事实与解释。Function Calling 违约时切确定性链，不把模型幻觉写成禁配结论。

### 3. RAG

短中文查询走 NGram + 内存 BM25；有 embedding 服务时写入/召回 pgvector。原理见 [technical-principles/🔴 断点地图：RAG 全链路深度理解.md](technical-principles/🔴%20断点地图：RAG%20全链路深度理解.md) 与 [technical-principles/别小看这两个for循环！中文RAG检索的底层核心解法.md](technical-principles/别小看这两个for循环！中文RAG检索的底层核心解法.md)。
